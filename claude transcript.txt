> Build me a Next.js AI-powered product ad generator app called "AdGen".
What it does
A user uploads a product image and writes a natural language prompt (e.g. "lifestyle photo on a marble countertop" or "summer Instagram ad with bold text"). The app analyzes the product using AI, then
generates a creative ad image. The user can then iterate conversationally ("make the background warmer", "add a headline") and the app regenerates with the changes applied.
Stack

Next.js 14 (App Router) + TypeScript
Tailwind CSS + shadcn/ui (Default style, Slate base color)
OpenAI API — GPT-4o Vision + DALL-E 3
Deploy to Vercel

API Routes
/api/analyze (POST)

Accepts { imageBase64: string }
Sends image to GPT-4o Vision
Returns JSON: { productType, description, dominantColors, style, suggestedPrompts[] }

/api/generate (POST)

Accepts { prompt, productType, productDescription, conversationHistory }
First calls GPT-4o to pick a strategy and write an optimized DALL-E prompt
Strategy is one of: background_swap, full_scene, or text_overlay — GPT-4o decides based on the user's prompt
Then calls DALL-E 3 (1024x1024) to generate the image
Returns: { imageUrl, strategy, strategyReason, adHeadline, adSubtext, dallePrompt }

/api/chat (POST)

Accepts { message, conversationHistory, productType, productDescription }
Calls GPT-4o to interpret the user's refinement request
Returns: { reply, newPrompt } — if newPrompt is non-null, the frontend re-calls /api/generate

Frontend (page.tsx)
Single page, dark theme (bg-gray-950), two-column layout on desktop:
Left column:

Drag-and-drop image upload zone
After upload: auto-analysis runs, shows detected product type + 3 clickable prompt suggestions
Prompt textarea + "Generate Ad" button (violet)

Right column:

Result canvas area — shows generated image, strategy badge, AI explanation, ad headline copy, and "Open Full Size" button
Chat panel (appears after first generation) — message history + input for iterative refinement

Agentic behaviors to highlight

Auto product detection — GPT-4o Vision identifies product type and describes it on upload
Prompt suggestions — AI suggests 3 creative prompts tailored to the detected product
Strategy routing — GPT-4o autonomously picks background_swap / full_scene / text_overlay based on the user's prompt
Strategy explanation — UI shows a badge explaining what approach was chosen and why
Conversational iteration — full chat history passed on every follow-up so the AI has context

UI details

Color scheme: gray-950 background, violet-600 accents
shadcn components: Button, Textarea, Badge, Separator
lucide-react icons: Sparkles, Upload, Send, RefreshCw, Download, ChevronRight
Loading states: spinner on analysis, spin animation on generation
App state machine: idle → analyzing → ready → generating → done
